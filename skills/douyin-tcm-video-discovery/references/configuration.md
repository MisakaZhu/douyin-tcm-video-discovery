# 配置、历史去重与文件输出

把 [config.example.json](../config.example.json) 复制到自己的工作目录，命名 `.douyin-discovery-config.json`。这是 agent 读取的任务参数，不是联网服务或自动执行配置；没有配置时也可直接在请求中提供参数。

任务中的明确要求优先于配置；配置优先于 skill 默认值。参数必须有效：目标数量、统计窗口和时长为正值，点赞阈值非负，最小时长不大于最大时长。异常配置说明实际问题，不能静默改成另一套筛选条件。

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `search_keyword` | `中医` | 抖音站内搜索关键词 |
| `target_count` | `30` | 希望核验通过的条数 |
| `min_likes` | `10000` | 点赞最低值，按核验时页面快照判断 |
| `min_duration_seconds` | `30` | 实际时长下限，含端点 |
| `max_duration_seconds` | `120` | 实际时长上限，含端点 |
| `history_window_hours` | `168` | 希望核对的滚动历史窗口 |
| `history_file` | `null` | 使用者自己的已使用/已生成来源 Markdown |
| `output_dir` | `./video-discovery-output` | 使用者要求文件交付但未指定目录时的保存位置 |
| `timezone` | `Asia/Shanghai` | 核验时间与窗口说明采用的时区 |

配置中的相对路径以配置文件所在目录为基准；直接在请求中指定的相对路径以当前任务工作目录为基准。没有配置时，默认输出目录以当前工作目录为基准。路径必须指向使用者提供的实际文件，不沿用作者电脑的目录。

历史清单优先读取“抖音视频 ID”或“视频 ID”列，将其视为字符串，避免长整数精度丢失。链接中的同一 ID 也作为同一视频处理。只有明确的 ID 才能建立视频级排除依据；标题匹配不够。

历史状态应按实际证据填写：

- `history_file` 为空且任务未提供历史时：“仅本批去重；历史未检查”。
- 提供的清单无法读取或没有可识别 ID 时：说明文件/字段缺项，不能当成已检查且无历史。
- 清单有 ID，但更新时间或窗口不完整时：排除其中全部 ID，注明具体覆盖不足与可核实的截至时间。
- 只有当前、可信记录覆盖整个指定滚动窗口时，才能报告该窗口历史去重已完成。

文件交付可命名 `抖音视频来源清单-日期.md`，内含核验时间、筛选参数、历史状态和视频表格。历史清单与候选清单用途不同，候选结果另存；同名结果文件已有时使用新的文件名，不自动覆盖。

真实历史记录、候选清单、页面证据、登录信息和私人配置留在使用者本机。发布代码或分发 skill 时只包含模板与说明，不打包这些运行资料。
