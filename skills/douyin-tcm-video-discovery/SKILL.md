# 抖音中医视频选源

从抖音站内“中医”搜索结果选出 **30 条不同的原视频**，默认每条点赞至少 1 万、实际时长 30—120 秒，交付能打开对应视频的实际分享链接。任务参数以使用者的明确要求为准。候选视频不能记作已经使用或生成的视频。

## 开始与本机配置

使用当前 agent 已提供的浏览器工具。安装 skill 文件不能代替浏览器能力检查；工具不可用时，说明实际缺项。工具有操作说明时先按其要求初始化，不假设某个作者的标签页、会话或登录状态可用。

任务中的明确参数优先。工作目录有 `.douyin-discovery-config.json` 时读取；指定其他配置文件时读取该文件。没有配置则使用上述筛选默认值，历史清单由使用者指定。配置模板为 [config.example.json](config.example.json)，路径规则、历史覆盖状态和文件输出见 [configuration.md](references/configuration.md)。

## 先读取并排除历史来源

1. 浏览新候选前，读取使用者指定的近期已使用或已生成来源 Markdown 的**当前内容**，不使用旧记忆中的 ID 清单代替。没有提供历史清单时可以继续选源，标注“仅本批去重；历史未检查”，不能声称已完成近 7 天历史去重。
2. 从“抖音视频 ID”或“视频 ID”列建立排除集。清单中每个 ID 都要排除，包括本机成片文件现已缺失、但记录为已核验使用或生成的条目。`/video/<ID>`、含 `modal_id=<ID>` 的分享链接，以及解析后指向同一 ID 的短链接都视为同一视频。标题相近不能证明相同，标题不同也不能推翻相同 ID。
3. 读取清单的更新时间和统计窗口。默认核对本次执行时的滚动 168 小时；配置或使用者另有要求时按实际窗口处理。若覆盖不足，依当前任务已授权的可信刷新流程处理并重读；无法核实新增记录时仍排除清单内全部 ID，说明去重依据截至何时。仅有候选搜索结果不能证明历史完整。
4. 不把本次仅收集的候选链接写入“已使用/已生成来源”清单；文件交付也不能覆盖该历史清单。

## 在抖音搜索结果中逐条核验

优先使用当前使用者指定的浏览器或可用的抖音搜索结果页；没有可用页面时，在抖音站内搜索配置的关键词，默认“中医”。仅从该搜索结果及其打开的视频详情继续找候选。登录或验证码需要使用者操作时保留进度，说明具体操作。

对每个候选打开视频详情，记录页面可核对的标题或主题、作者、点赞数、完整时长和视频 ID。只有以下条件全部满足才计入目标数量：

- 页面显示的点赞数明确达到实际阈值，默认 **10,000**。不足、模糊或无法判断的条目不计入；点赞数是核验时的快照。
- 实际视频时长在设定范围内，默认 **30—120 秒，含两个端点**。不要从搜索卡片、文案或进度条猜时长。
- 视频 ID 不在历史排除集，也不与本次已选视频重复；持续维护已见 ID 集，避免反复检查。
- 通过该视频的分享操作取得链接，并打开或解析链接，确认它指向刚核验的同一视频 ID。保留实际分享 URL；不能凭 ID 拼出链接冒充“复制的分享链接”。

搜索卡片、网页摘要、相似标题或未经打开的短链接不能代替详情核验。遇到页面访问限制或无法核实某项时，记录具体缺项并继续处理能核实的候选；不能用猜测凑数。

## 交付

输出核验时间和时区、实际筛选参数、历史清单覆盖窗口与去重状态，以及下表。默认使用北京时间；使用者指定其他时区时标明实际时区。要求文件时另存 UTF-8 Markdown，文件名和保存目录按当前任务处理；未指定目录时使用配置的 `output_dir`。

| 序号 | 视频标题或主题 | 作者 | 点赞 | 时长 | 视频 ID | 分享链接 |
| ---: | --- | --- | ---: | --- | --- | --- |

交付前核对目标行数、ID 唯一性、历史排除集、每行的点赞数与实际时长，以及分享链接与 ID 的对应关系。无法核满目标数量时，只输出实际核验通过的条目，说明缺少数量和原因；不得加入未核验条目或宣称完成目标数量。

此任务的交付是来源清单。下载、转载、数字人生成和发布属于后续任务，按使用者的实际请求与素材使用权处理。安装或更新本 skill 只处理 skill 文件，不自动搜索、修改历史记录、下载视频或发布内容。
