# 抖音中医视频选源 Agent Skill

让 agent 在抖音网页搜索中医视频，逐条核验点赞、实际时长、视频 ID 和分享链接，排除使用者提供的历史来源，生成 Markdown 清单。默认目标是 **30 条、点赞至少 1 万、时长 30—120 秒**。

这是 `douyin-tcm-video-discovery` 的脱敏公开分发版，适用于支持本地 skills、文件工具及浏览器操作的 Codex 或具备等效能力的 agent。网页选源由使用者自己的 agent 和浏览器工具执行；仓库提供流程说明、配置模板与分发检查工具。

## 可以直接发给用户的完整安装提示词

将下面整段复制给自己的 agent：

```text
请帮我安装「抖音中医视频选源」skill。

官方原仓库：
https://github.com/MisakaZhu/douyin-tcm-video-discovery

需要安装的目录：
skills/douyin-tcm-video-discovery

请按以下要求完成：

1. 只使用上述原仓库，不替换成 fork 或其他镜像。先只读检查仓库身份、默认分支、README、SKILL.md、agents、references、配置模板和仓库里的可执行文件，确认没有泄露凭证、异常二进制、隐藏联网或与选源任务无关的操作。发现实际风险时说明具体问题；检查通过后直接安装。
2. 优先使用当前环境自带的 skill-installer，安装指定目录并保留全部文件。Codex 安装到 CODEX_HOME 对应目录下的 skills；未设置 CODEX_HOME 时使用 ~/.codex/skills。其他 agent 先确认其官方支持的本地 skills 机制，不猜安装位置或声称已经兼容。
3. 如果存在同名 skill，先读取并比较，不覆盖或删除。内容一致则报告已安装；不同则说明差异，给出保留原文件和私人配置的升级方案，等我决定后再更新。
4. 安装后重新读取目标 SKILL.md，检查 YAML、名称、全部相对引用、配置模板和文件完整性。报告实际安装路径、仓库来源、所用提交 SHA，以及何时可被当前 agent 发现。
5. 检查当前 agent 能否使用浏览器打开网页、搜索、读取视频详情并操作分享链接。能力缺失时说明具体缺项，不自动安装浏览器扩展或额外软件；安装文件成功不等于网页选源环境已就绪。只有需要网页登录时再由我处理实际登录或验证码，不索取或公开账号凭证。
6. 首次选源时，再按 config.example.json 帮我配置自己的关键词、数量、点赞与时长范围、历史清单和输出目录。不继承作者路径或历史视频 ID；未提供历史时标注“仅本批去重；历史未检查”。真实历史记录、候选清单、页面证据和私人配置留在本机，不提交到 GitHub。
7. 完成后给我一条可以直接复制的 $douyin-tcm-video-discovery 调用示例。本次只安装和检查，不实际搜索、不改写历史、不下载或转载视频、不生成数字人视频、不发布内容。

在已授权安装范围内尽量自主完成，不对常规步骤反复询问；确实需要我处理时，说明已完成部分、具体缺项和下一步。
```

## 使用示例

安装后给 agent：

```text
使用 $douyin-tcm-video-discovery，在抖音网页搜索“中医”。
选出 30 条点赞至少 1 万、实际时长 30—120 秒的不同视频。
历史来源清单使用我提供的 ./my-video-history.md，排除其中全部视频 ID。
逐条打开详情核验，并通过分享操作取得真实链接，确认每个链接指向对应视频。
把清单另存到 ./video-discovery-output，注明核验时间、历史覆盖状态和每条视频的标题、作者、点赞、时长、ID、分享链接。
不足 30 条时报告实际通过的条数、缺少数量和原因。
```

如没有历史清单，将示例中的历史句改为：“本次没有提供历史清单，只做本批去重，并明确标注历史未检查。”

参数可直接写在请求中，也可复制 [config.example.json](skills/douyin-tcm-video-discovery/config.example.json) 到自己的工作目录，命名 `.douyin-discovery-config.json`。完整规则见 [configuration.md](skills/douyin-tcm-video-discovery/references/configuration.md)。配置模板中的 `history_file` 默认为 `null`。

## 核验规则

- 点赞采用核验时页面快照；数字模糊或无法确认达到阈值时不计入。
- 时长采用实际视频时长，包含上下限；搜索卡片和文案不能代替详情核验。
- 历史与本批均按视频 ID 去重；同一 ID 的短链接、`/video/` 链接和 `modal_id` 链接视为同一视频。
- 分享 URL 通过视频的分享操作取得，并验证对应 ID；不凭 ID 拼链接冒充复制结果。
- 历史未提供、无法读取或窗口覆盖不足时，如实注明实际去重范围；候选链接不能写成已使用或已生成记录。
- 未核满目标数量时交付实际核验通过的条目，不用未验证结果凑数。

清单包含核验时间、筛选参数、历史状态，以及“序号、视频标题或主题、作者、点赞、时长、视频 ID、分享链接”七列。

## 环境与分发内容

需要当前 agent 支持本地 skills、文件读取和浏览器操作，并能访问抖音网页。网页登录、验证码和可见结果会影响本次能完成的数量；缺少浏览器能力时按实际情况报告。skill 本体只有说明、UI 元数据和配置模板，无运行脚本或第三方 Python 依赖。

```text
skills/douyin-tcm-video-discovery/
  SKILL.md
  agents/openai.yaml
  config.example.json
  references/configuration.md
tools/audit_package.py        分发文件、引用和明显私人信息检查
```

仓库内的检查工具需要 Python 3.10+，只用于维护分发包，不是使用 skill 的依赖：

```bash
python tools/audit_package.py
```

分发检查和隔离安装检查的范围是文件、元数据、引用和安装完整性；网页选源效果须由实际任务逐条核验。维护检查不能当成已搜索或已验证 30 条真实视频。

公开包只包含模板与说明；真实历史、视频、搜索结果、页面证据、浏览器会话和本机配置由使用者保存在自己的环境中。`.gitignore` 作为辅助，发布前仍应核对实际文件。
